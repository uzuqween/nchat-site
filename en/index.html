NChat AI

A desktop chat with language models that works with your computer directly: it reads and writes files, runs commands, manages git and connects MCP servers.

Features

Files

Read, search by name and content, edit fragments, create, copy and move files right from the chat.

Shell and system

Run commands, launch programs, manage processes, services and environment variables, all behind confirmations.

Git

Status, diffs, history, commits, branches, push and pull without switching to a terminal.

MCP servers

Connect external tools over the Model Context Protocol. Available tools depend on the servers you add.

Parallel chats

Work in several conversations at once, with a status indicator for each request.

Live previews

HTML, SVG and Mermaid diagrams from the model's reply render right next to the code.

How it looks

Request → tools → result. Every action the model takes is visible in the chat.

[⌂]

Project boundary

Writing outside the project folder always needs confirmation, no exceptions.

[✓]

Every step visible

Statuses [✓] done, […] thinking, [✕] error show what the model is doing right now.

[↯]

Nothing behind your back

If a tool it needs (ffmpeg, sqlite3, pip-audit) is missing, NChat shows the install command instead of installing it itself.
