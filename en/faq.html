Frequently asked questions

Everything people usually ask about NChat AI — a free AI chat for Windows.

What is NChat?

NChat (NeuralChat) is a free desktop app for Windows for working with language models. It is an AI chat with access to your computer: it reads and writes files, runs commands, manages git and connects MCP servers — all in one window.

Is NChat free?

Yes, NChat is free. You can download the latest version from this site or from the GitHub releases page.

Which systems are supported?

Windows 10 or newer, 64-bit (x64).

It needs the Microsoft Edge WebView2 Runtime: it is built into Windows 11, and on Windows 10 it usually comes with the Edge browser. If the NChat window does not open, install the WebView2 Runtime from Microsoft.

Do I need to install NChat?

No. NChat is a portable build: download NChat.exe, save it to any folder and run it. No installation needed.

Is it safe to give an AI access to my computer?

You decide what it may do. Tools that write files or start processes ask for permission first. Every step the model takes is shown in the chat with a status, and NChat never installs the utilities it needs on its own — it only shows the install command.

Can NChat change files outside my project?

Only with your confirmation. Writing outside the project folder always needs confirmation, no exceptions.

Where are my chats and settings stored?

Locally on your computer, in the %APPDATA%\nchat folder. When you upgrade from older versions, your data is picked up automatically. Network requests go only to the model provider you chose, to connected HTTP MCP servers and to GitHub when checking for updates.

What are MCP servers and why use them?

MCP (Model Context Protocol) is an open protocol for connecting external tools to an AI. You can connect MCP servers in NChat and the model gets their tools. The available tools depend on the servers you connect.

What can NChat do with git?

Status, diffs, history, commits, branches, push and pull — right from the chat, without switching to a terminal.

Can I run several chats at once?

Yes. NChat supports parallel conversations, and each request has its own status indicator.

What are live previews?

If the model replies with HTML, SVG or a Mermaid diagram, NChat renders the result right next to the code.

How do I update NChat?

Since version 1.1.0, NChat checks for new versions through GitHub Releases on its own and verifies the file's SHA-256 checksum before updating. You can also update manually: download the latest NChat.exe from this site or from GitHub releases. The changelog is in the “What's new” section on the home page.

Where can I ask a question or report a bug?

In the project's Telegram channel: t.me/NChat_AI.
